# 原整合版与当前优化版实跑对比

原整合版来自 Git 提交 `df21cd2`，当前优化版取工作区代码。两版在同一台 Windows 电脑上依次运行，使用 Python 3.12.10、NumPy 1.26.4、相同赛方 SDK、相同公开数据和模拟模型建议，按单线程 CPU 训练。A、B、C 各十轮。
逐轮核对两版共 60 条回执。对应轮次的起点、训练与验证摘要、随机种子和生效参数一致，候选与最终选中的检查点也完全一致。

## B 单独开启 L2-SP（强度 1.0）

两组使用同一初始检查点、逐轮批次、种子和训练超参数。每组按自己的采用结果继续训练。
