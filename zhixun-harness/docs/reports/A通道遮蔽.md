# 提分方案第二段｜A 气体传感器通道遮蔽

## 输入和实验

UCI 原始资料把 128 列按传感器分成 16 组，每组连续 8 列。对公开训练与验证投影，逐行核对原始第 1、2 批的 445 和 1,244 条记录，验证了特征编号、列值、类别与行号。检查点按 `features[0..127]` 顺序读取。 [UCI 数据说明](https://archive.ics.uci.edu/dataset/224/gas%2Bsensor%2Barray%2Bdrift%2Bdataset) · [映射校验结果](../results/a-sensor-mapping.json) · 校验脚本（本地留档）

在 `sensor_mask_v1` 配方中，每个 epoch 由原种子和累计 epoch 导出独立的遮蔽随机序列，随机抽取约四分之一训练样本，把每个选中样本的一个随机传感器的连续 8 项标准化特征设为 0。梯度更新次数、Adam、验证和预测流程沿用原策略。组级遮蔽的思路参考 PyTorch。 [PyTorch 通道遮蔽源码](https://github.com/pytorch/pytorch/blob/main/torch/nn/modules/dropout.py)

标准组复现 V2 各轮候选摘要。两组使用相同初始检查点、种子、十批训练投影、公开验证、学习率、批大小 128 和每候选 1 epoch。每组有十次模拟调用、十次训练和十次候选测量。全链按各组实际采用的父模型继续。另取唯一含乙醛的第 7 轮，在同一父模型、同一批训练数据上做标准与遮蔽配对。

第 7 轮同父配对的候选 Macro-F1 都是 **0.735731**，乙醛仍为 0/109。遮蔽组最终仍把 108 条乙醛判成乙醇，另 1 条判成甲苯。乙烯正确数从 313/334 降到 299/334。两组完整混淆矩阵、六类支持数、每轮采用决定与配对结果见原始明细。正式 Token 用量仍需真实网关回执。 [原始明细](../results/a-sensor-masking.json) · 标准组回执（本地留档） · 遮蔽组回执（本地留档）

**决定**　固定这一组遮蔽参数未修复乙醛错判，最终 Macro-F1 比标准低 **0.00842**。A 默认继续用标准配方。遮蔽入口保留为可重跑的研究选项，后续需有益的开发结果与独立公开批次复核才考虑采用。

## 本地复现

在 `zhixun-harness` 下用已有的项目 Python 执行，名称使用空闲值。

```powershell
python -B -m stage2_official.rehearse --name improve-a-reference --task A --rounds 10
python -B -m stage2_official.rehearse --name improve-a-sensor-mask --task A --rounds 10 --scenario sensor_mask
```

第 7 轮配对由训练器接收标准组第 6 轮候选检查点、标准组第 7 轮训练投影和原公开验证投影，参数为 `A-7 0.001 128 1 --recipe sensor_mask_v1`。15 项项目测试通过，镜像上下文清单核对通过。复核时适配了旧研究回执的行数字段，并用同一训练进程权限读取配对产物。 复核脚本（本地留档）
