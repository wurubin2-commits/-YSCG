## A 与 B 的结果

- A 用整份公开验证的 Macro-F1 和准确率筛查学习率放大、缩小与固定学习率。可取得的最高值仍为 0.7368 和 88.83%。公开验证包来自同一个气体批次，三个连续片段的留出只能检查这一批内部表现。 [A 复核指标](../results/a-c-learning-rate-probes.json)
- B 的固定学习率 0.001 让整份公开验证的 RMSE 从 570.76 降至 569.65 分钟，逐轴承留出的总体 MAE 从 580.42 升至 581.36 分钟。只训输出层并提高学习率在整份公开验证降至 558.37，逐轴承留出的 RMSE 却从 686.70 升至 727.60，三个轴承留出组均退步。测试过的 Huber、L2 与学习率变体在整集和逐组留出指标上也各有得失。当前保留 B 的标准续训作为默认策略。 [逐轴承结果](../results/b-learning-rate-probes.json) · 回放脚本（本地留档）
