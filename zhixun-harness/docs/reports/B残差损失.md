# 提分方案第三段｜B 轴承寿命残差损失

在标准化残差的训练小批上使用 `mean((e − mean(e))²) + λ × mean(e)²`，固定 `λ = 0.5`。缩小批内平均偏差对更新的影响，同时保留原始检查点、Adam 状态、标准化和以分钟计的预测。轴承标识只用于离线分组。单测验证 `λ = 1` 在 `1e-12` 的绝对浮点容差内复现 MSE 的损失、梯度与一次续训的参数和矩状态，并用有限差分检验了 `λ = 0.5` 梯度。

标准组复现 V2 候选检查点。两组在同一台 Windows 电脑依次运行，使用 Python 3.12.10、NumPy 1.26.4、相同初始检查点、十批公开训练投影、公开验证、种子 42、相同学习率、批大小 128、每候选一轮训练。逐轮核对了有效的训练参数和更新步数。

## 同一父模型配对

在标准组每轮的父检查点上独立训练一份新损失候选。第 3 轮两种候选都优于父模型（656.68 分钟），新损失的候选 RMSE 为 585.92，高于标准候选的 577.68。分解结果显示两种策略都减小了组均值偏差平方，新损失对该项的修正较小。

第 5–9 轮，新损失在第 5、7、9 轮使组均值偏差平方增幅低于标准组，在第 6、8 轮增幅更高。五轮的新候选仍都比各自父模型差。 [十轮配对明细](../results/b-residual-loss.json)
