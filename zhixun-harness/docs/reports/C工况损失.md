# 提分方案第四段｜C 发动机工况分组损失

## 训练侧的工况证据

仅使用公开训练投影的三个 `inputs.settings` 值确定六个工况中心。匹配容差依次为 0.05、0.005、0.5。训练的 113,089 条记录均匹配；未识别设置按 `Other` 归类。发动机编号和 FD 子集只用于离线审计。

| 工况中心 | 训练样本 | 训练侧三个整机组的起点 RMSE（循环） |
| --- | ---: | --- |
| (0, 0.00, 100) | 43,840 | 58.39 / 59.98 / 47.86 |
| (10, 0.25, 100) | 12,259 | 49.84 / 60.56 / 51.60 |
| (20, 0.70, 100) | 12,219 | 47.84 / 61.62 / 52.14 |
| (25, 0.62, 60) | 12,173 | 51.94 / 62.66 / 53.87 |
| (35, 0.84, 100) | 12,214 | 48.89 / 63.80 / 50.42 |
| (42, 0.84, 100) | 20,384 | 48.86 / 62.96 / 52.10 |

工况 `(25, 0.62, 60)` 的 RMSE 在三个训练侧整机组中均高于 `(10, 0.25, 100)` 和 `(20, 0.70, 100)`。起点检查点已见过训练投影，该现象用于检验工况分组假设。 [训练侧原始诊断](../results/c-condition-diagnosis.json)

## 运行方式

从同一官方起点检查点开始，比较 V2 标准续训、V3 学习率减半与新工况损失。十轮公开数据摘要、种子、批大小 256、epoch 和梯度更新次数一致。标准与工况损失使用相同学习率，三组各走自己的父模型链。标准与减半组使用已有的同环境模拟回执，工况组在本阶段新跑十轮。

工况损失固定为 75% 逐样本 MSE 与 25% 工况等权 MSE。基于当轮训练样本数计算权重。样本量低于 128 的组合并到 `Other`。合并后若少于两个工况或仍有不足 128 的非空组，就执行标准续训。第 1、6 轮回退标准 MSE，另外八轮使用加权。本方案借鉴按组求平均损失的设计。 [Group DRO 作者的分组损失](https://github.com/kohpangwei/group_DRO/blob/master/loss.py)

## 整机留出复核

按「FD 子集＋机号」保留整台发动机，每折用另外两组选择候选，留出组只在该折结束时评分。复核对象来自已有公开数据。

| 指标 | 标准续训 | 学习率减半 | 工况损失 |
| --- | ---: | ---: | ---: |
| 留出组 1 RMSE（循环） | 52.1632 | 51.8053 | 52.1612 |
| 留出组 2 RMSE（循环） | 48.5038 | 48.2035 | 48.4850 |
| 留出组 3 RMSE（循环） | 55.4101 | 54.9887 | 55.4029 |
| 按样本汇总 RMSE（循环） | 52.1105 | 51.7484 | 52.1016 |
| 按样本汇总 MAE（循环） | 37.8823 | 37.7743 | 37.8721 |
| PHM’08 非对称参考分数（十亿） | 5.6010 | 4.4203 | 5.5531 |

**采用决定**　工况损失在整机留出汇总中的 RMSE 改善不足 0.01 循环，整份公开验证的最终 RMSE 略升，未达到预设的 1% 开发目标。学习率减半在整机留出中更好，但整份公开验证的非对称参考分数升高，结合此前换序退步，C 保留标准续训为默认。两个新策略保留为独立实验选项。 [既有减半学习率与换序结果](学习率效果复核.md)
