# Harness 瓶颈与整合建议

## 当前瓶颈

既有 V2 与 V3 默认回放逐轮复现同一候选检查点和采用结果。SDK 入口已通过本地十轮回放，模型接续和同轮采用行为有可追溯证据。眼下最需要改进的是赛前筛选训练策略的方法。现有验证回放用脚本固定学习率，默认只走标准配方，因此它能核对执行正确性。真实模型是否会根据诊断选择更有效的动作，仍需单独实测。 [固定基线与十轮记录](固定基线.md) · [当前决策入口](../../stage2_official/contest_submission.py)

- 一轮一个候选和全程最多 12 个 epoch 是当前项目策略。基准实际尝试 10 个 epoch，A、B、C 分别执行 10、60、450 次梯度更新。因此记录更新步数和单次训练耗时比单看 epoch 更能解释训练成本。正式轮次与真实回执要求继续按 SDK 处理。 [官方 SDK 说明](https://rsi-index.115.zone/#rules)
- 当前历史的 `same_batch` 标记由父检查点和训练摘要决定。实验比较还需核对验证摘要和指标口径。换验证集后，旧记录的候选与父模型分差仅描述原来那轮。训练去重仍以会产生相同检查点的输入和生效参数为准。 [现有历史逻辑](../../stage2_official/policy.py)

## A 的补充排查

使用已锁定的十份公开训练投影、同一起点、种子、学习率、每轮一个 epoch 和同一公开验证投影复跑。只改变批大小。纯推理校正独立使用标准组最终模型和已授权公开训练类别计数，先验加一平滑，固定 `τ=1`。乙醛有效验证样本为 109 条。 [先验校正原始实现](https://github.com/google-research/google-research/blob/master/logit_adjustment/main.py#L120-L128) · 实验程序（本地留档） · [核对结果](../results/a-bottleneck-probes.json)

| A 探针 | 总梯度更新 | 十轮最终 Macro-F1 | 乙醛识别 |
| --- | ---: | ---: | ---: |
| 标准批大小 128 | 10 | 0.736778 | 0/109 |
| 所有轮次改用 32 | 20 | 0.736778 | 0/109 |
| 只有当前训练批包含乙醛时用 32 | 11 | 0.736620 | 0/109 |
| 标准模型独立做固定先验校正 | 无新增 | 0.673975 | 0/109 |

将模型的「乙醛 logit 减乙醇 logit」用作二类排序信号，公开验证中初始检查点 AUC 为 0.140，标准续训结束后为 0.102。这一信号已经在起点表现出逆向排序。对任一类别加固定偏置只会整体移动两类分差，排序本身保持不变。上述结果只覆盖一个公开气体验证批次；证据更支持优先检查训练如何学习跨批次特征，而非继续在同一批上调固定偏置。

## 推荐的整合方式

保留现有 `contest_submission.py` 作为官方入口，用现有 `trainer.py`、`rehearse.py` 和诊断脚本建设轻量赛前对照。借用以下源码设计，在本项目已有 NumPy/CPU 环境独立实现。 [完整开源源码核对](Harness开源源码调研.md)

| 上游 | 借用的设计 | 放入项目的位置 |
| --- | --- | --- |
| autoresearch | 固定评估程序和预算，只改一个训练环节并登记结果。 | 赛前实验固定 SDK 投影、父检查点、版本摘要和同轮主指标。 [试验规程](https://github.com/karpathy/autoresearch/blob/master/program.md) |
| OpenEvolve | 通过较低成本的评估才进入下一阶段。 | 先做少量同父同批对照，再跑完整十轮。独立留出只用于最终复核。首批抽查被初筛跳过的方案，以评估错淘汰风险。 [分级评估源码](https://github.com/algorithmicsuperintelligence/openevolve/blob/main/openevolve/evaluator.py#L420-L547) |
| Microsoft FLAML | 局部搜索同时记录收益、训练资源和耗时。 | 比较一项变动时固定其他条件。把尝试步数、耗时和失败原因与指标一起记录，换批后重新依据当轮结果判断。 [FLOW2 源码](https://github.com/microsoft/FLAML/blob/main/flaml/tune/searcher/flow2.py#L395-L454) |

A 的下一组实验应先比较乙醛和乙醇在不同传感器组上的跨批次排序失真，明确一个针对特征尺度的续训假设。使用预先固定强度、在当轮训练输入上做整通道幅度扰动，与标准续训同父同批比较。仅在六类 Macro-F1 和乙醛召回的对照出现改善后做十轮与独立气体批次复核。若独立批次暂未开放，标明单公开批次结论。B 和 C 分别以整轴或整机留出及主指标方向决定是否继续开发，各任务分别验收。

本阶段保存了诊断程序、实验回执与整合方案。比赛入口与默认配置沿用此前版本。正式分数与 Token 用量待真实平台验证。
