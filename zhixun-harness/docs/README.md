# 智训引擎 Harness 交接入口

以 V2 `df21cd2` 为基准交接当前 V3。首要目标是提高工业模型的主评测指标。当前三项默认策略沿用标准续训，新增配方供离线复验。所有列出的模型分数均来自公开数据，正式隐藏集评分和真实 Token 用量待平台复核。

## 接手顺序

1. 先看 [赛题规则与接续备忘](赛题规则与接续备忘.md)，核对平台合同、当前版本与下一段任务。
2. 按 [源码与运行说明](../README.md) 获取赛方 SDK 和 CPU 工业模型包，配置 Python 3.12，运行本地单测与模拟宿主。公开数据、检查点、密钥和镜像在各自获准的本地环境准备。
3. 查看下表的实验结果及汇总 JSON。原始运行回执和单轮模型由执行机器保管。按各篇报告给出的命令可重建本地对照。
4. 从 A 传感器排查接续。先找乙醛、乙醇在跨批次时排序变化最大的传感器组，再对同父、同批和同预算的一组候选做轻微通道幅度扰动。用 Macro-F1 和乙醛召回决定是否进入十轮及独立气体批次复核。 [瓶颈分析与整合建议](reports/Harness瓶颈与整合建议.md) · [开源源码调研](reports/Harness开源源码调研.md)

| 任务 | 默认公开主分数 | V3 实验结论 |
| --- | --- | --- |
| A 气体分类 | Macro-F1 0.7368，准确率 88.83% | 通道遮蔽降至 0.7284，乙醛仍是 0/109。 [报告](reports/A通道遮蔽.md) |
| B 轴承寿命 | RMSE 570.76 分钟 | 残差损失在整份公开集降至 568.24，整轴留出汇总升至 688.45。 [报告](reports/B残差损失.md) |
| C 发动机寿命 | RMSE 51.8281 循环 | 工况损失为 51.8344，学习率减半为 51.7725，后者的非对称参考分数在整份公开集上升。 [报告](reports/C工况损失.md) |

## 目录

| 路径 | 内容 |
| --- | --- |
| `main.py`、`round_review/` | 本地十轮对照入口、回执核对和图表输出。 |
| `stage2_official/` | 赛方 SDK 回调、实验策略、CPU 训练、工况分组、容器构建与模拟宿主。 |
| `stage1_local/`、`stage2_local/` | 初始模型检查、历史本地跑通工具及测试。 |
| `docs/reports/` | V2/V3 对照、基线验收、阶段报告和开源调研。 |
| `docs/results/` | 已核对的实验指标、逐轮汇总与混淆矩阵。 |

其他队友的仓库顶层代码和原有说明保留在各自位置。正式入口由赛方 SDK 模板提供 `/app/harness.py`。
