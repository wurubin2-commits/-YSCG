# 工业模型提分方案

**目标是让赛方工业模型在 CPU 上从指定父检查点续训十轮后，A 的 Macro-F1 更高，B 和 C 的 RMSE 更低，同时改善十轮平均表现和最差阶段。** 建议先做 A，再做 B，最后做 C。下面的数字来自已有公开回放及对其最终权重的只读复算。新增训练方法均是待检验假设。

## 三个优先实验

### 1. A 先试传感器通道遮蔽，观察乙醛和乙醇能否分开

公开包只有一个气体验证批次。训练乙醛有 25/30 判对，验证乙醛有 0/109 判对，使跨批次传感器响应变化成为值得优先检验的假设。训练集中乙醛少，也可能参与造成错误。现有十轮模拟按顺序切片，乙醛只在第七轮出现，多轮仅有一种气体；在单类批次内均衡采样没有第二类可抽。本项目研究路径已有 `class_balance` 加权配方，可用作对照。

借鉴 PyTorch 按通道随机遮蔽的做法。先按原始特征说明核实 16 个传感器与 128 列的对应关系，再在标准化后的当轮训练输入上，按固定种子给部分样本随机遮蔽一个传感器对应的整组特征，让模型也能利用其他通道。首个预设配置可取四分之一样本、每个遮一组，预测照常使用全部 128 列。只改训练输入，保持标签、更新步数、Adam 和预测接口。若通道映射不能核实，先做已有加权配方的独立对照。 [PyTorch 通道遮蔽源码](https://github.com/pytorch/pytorch/blob/main/torch/nn/modules/dropout.py) · [UCI 数据集说明](https://archive.ics.uci.edu/dataset/224/gas%2Bsensor%2Barray%2Bdrift%2Bdataset)

同轮对比标准配方与遮蔽配方，报告六类混淆矩阵、乙醛召回率、乙醇精确率及两类各自 F1。按既有实现计算主指标，缺类切片另列支持数和计算口径。若只是增加乙醛预测、同时吞掉大量乙醇样本，以整体 Macro-F1 判定取舍。在赛方另行开放的后续整批上复核前，仅标为单批探索结果。原始资料目录中的其他批次不能据其存在就视为已授权的独立验收集。

### 2. B 减弱单批的整体偏移，同时学习批内寿命差异

此前只训输出层时，整份公开 RMSE 从 570.76 降至 558.37，逐根留出汇总 RMSE 却从 686.70 升至 727.60 分钟。训练回放第 4、5、7、8、9 轮各自只含一根轴承的片段。一个可检验的解释是，模型把局部片段的平均寿命过度推广给其他轴承。先复用历史父子检查点，逐根比较预测均值的移动与去均值后的残差，判断候选更新是否确实以整体平移为主。 [逐根留出结果](results/b-learning-rate-probes.json)

本次逐轮复算已支持进一步实验。把公开验证 MSE 拆成按样本数加权的「各轴承平均偏差的平方」和「各轴承内部残差方差」。第 5 至 9 轮的五个候选，其轴承内部残差方差都下降了，但平均偏差的平方增加更多，整体 RMSE 因而上升。第 3 轮则是修正平均偏差带来较大收益，所以也要验证新配方能否保住早期进步。

建议试一个项目自拟的损失函数。对当轮训练小批的标准化残差 `e = 预测 − 真值`，计算 `mean((e − mean(e))²) + λ × mean(e)²`。第一项学样本间的寿命差异，第二项学绝对寿命。λ=1 时等于原始均方误差。首个实验锁定 λ=0.5，减弱同批平均偏差对参数的推动。直接计算小批均值即可，无需成对枚举，训练和推理都无需输入轴承编号。先验证 λ=1 的损失、梯度和一步更新在浮点容差内等价。保留绝对误差项也很重要，赛题最终按分钟打分。

若候选本来就能纠正各组同向偏差，减弱该项可能有害。按整根留出复核汇总 RMSE、MAE、三根各自误差及最差轴承，同时保留原始按样本计分。七次回退已经记录过，接受次数只用于解释过程。 [十轮回顾](reports/旧版十轮回顾.md)

### 3. C 用运行设置识别工况，检查较难工况的误差

先用训练输入已有的三项运行设置定义工况组。分组规则在开发训练侧确定并冻结，正式轮次只用当轮授权输入；FD001–FD004 和整台发动机标识只用于离线审计。先检验工况内误差是否存在可重复的差别，FD004 误差较大本身不能证明工况是成因。

借鉴 Group DRO 先分组计算损失的做法。首轮实验可固定用 75% 的逐样本 MSE 加 25% 的当轮有效工况等权 MSE。对小样本组合并或回落标准 MSE 的最小样本数在实验前固定，仅有一个有效工况时走标准更新。使用相同学习率与 V2 做单因素对照，再单独和 V3 现有半学习率配置比较。沿用已有 NumPy、非负循环数输出和父检查点归一化。以相同发动机、相同样本量计算 RMSE、MAE 及赛方口径的 NASA 非对称评分，特别查看高估寿命的尾部误差。 [Group DRO 作者的分组损失源码](https://github.com/kohpangwei/group_DRO/blob/master/loss.py)

## 代码接入与验收

1. **固定对照。** 每项从赛方初始检查点启动，后续使用该实验链被选中的父模型。固定数据摘要、原始种子、轮次划分和训练预算。分开做同父同批的单轮机制对照，以及各自独立选择父模型的完整十轮对照。第一阶段交付三项错误明细和预先确定的比较表。
2. **逐项加配方。** 在 V3 工作树的 `stage2_official/continuation.py` 增加 NumPy 实现，`trainer.py` 记录实际参数，`policy.py` 限定建议并把配方版本与生效参数纳入去重。已有 SDK 入口负责当轮调用、候选登记、采用或保留父模型。每轮一次模型建议、最多一个候选。开发时用模拟建议固定预算和配方，正式轮次按 SDK 获取真实回执。每次只开一种新改动。
3. **冻结配方后复核。** A 用后到的合规完整批次，B 按整根轴承，C 按完整发动机（子集＋机号）隔离。仅监控集参与逐轮采用，最终留出组只评分。旧公开组已用于选思路，继续跑它们属于开发复核。原顺序作为主试验，换序仅作离线压力测试。比较十轮平均主指标、最差轮和最终轮，出现可比退化时再记录恢复轮数。
4. **决定哪些可以启用。** 建议团队预先采用一个开发目标，例如 A 的 Macro-F1 绝对提高 0.01，B/C 的 RMSE 相对降低 1%；这些是建议的工程目标。以同划分的 V2 为参照，同时检查分组结果、辅助指标、CPU 时间、峰值内存和候选次数。留出或换序出现明显反转时继续保留为实验选项。真实 Token 用量以网关回执为准。最终可交付一张 V2／V3／候选对照表，每个任务独立决定是否启用。

以下方法可作为后备实验或离线诊断。父子插值在优化器状态和平台指定父检查点的衔接得到验证前，只用于离线分析。

## GitHub 方法来源

以下源码分别给出可复用的公式、采样步骤和验证划分。各项在本项目上的取舍由对照实验决定。

**A · 校正少数类的判决分数。** Google Research 的长尾分类实现提供两条独立路径。推理时，对第 c 类分数使用 `z_c − τ log(π_c)` 后再做 softmax。训练时，则是把 `τ log(π_c)` 加到原分数后计算交叉熵。源码用极小正数保护对数。两条路径应各自与 `τ=0` 对照。项目可先试推理校正，按类别名称对齐六项先验，只用决策时已开放的训练标签计数，缺类时预先约定平滑。同一个校正量只应用一次。原实现评估 CIFAR 长尾图像的准确率。气体传感器有跨批次漂移，应观察每类精确率、召回率及六类 Macro-F1，才能判断校正是否有利。[推理端源码](https://github.com/google-research/google-research/blob/master/logit_adjustment/main.py) · [训练损失源码](https://github.com/google-research/google-research/blob/master/logit_adjustment/utils.py) · [作者实验设置](https://github.com/google-research/google-research/tree/master/logit_adjustment)

**A · 类均衡采样。** Facebook Research 的 `ClassAwareSampler` 先选类别，再从该类的索引中轮换抽样。作者把轮长设为最大类样本数乘类别数，直接照搬会增加更新次数。项目对照应固定每轮梯度更新步数、学习率和种子，只在该轮允许读取且实际有样本的类中采样。先单测采样。与先验校正叠加时，重复补偿稀有类可能降低其精确率。[ClassAwareSampler 源码](https://github.com/facebookresearch/classifier-balancing/blob/main/data/ClassAwareSampler.py)

**B、C · 用父检查点约束单轮更新。** WiSE-FT 作者示例对同源模型的每个同名权重计算 `(1−α)θ_parent + αθ_child`。它在视觉分类模型上比较插值前后的准确率。针对现有 NumPy MLP，可先验证同一父子链、相同张量结构及标准化参数下的插值，保留 `α=0` 和 `α=1` 两端作对照。示例仅处理推理权重，未定义本项目的 Adam 一阶矩、二阶矩与步数如何随插值变化。若要继续下一轮，优先从已核验的原父或原子检查点续训，单独验证插值权重的推理指标。[WiSE-FT 作者最小示例](https://github.com/mlfoundations/model-soups/blob/main/wise-ft-example.py)

**B、C · 直接混合回归预测。** scikit-learn 的 `VotingRegressor.predict` 对各回归器的预测做加权平均。本项目可先用同一批样本比较 `(1−α)ŷ_parent + αŷ_child` 的 RMSE，B 另列 MAE 与每根轴承的有符号平均残差 `mean(ŷ−y)`。两个输入都取最终非负预测，并保持同一单位，B 用分钟、C 用循环。这样可在推理时比较父子模型误差是否互补。若采用双模型混合，须同时计入两次前向推理成本，并核对交付接口是否支持两个检查点。tanh 隐层使预测混合与参数插值通常产生不同结果。[VotingRegressor 源码，1.6.1](https://github.com/scikit-learn/scikit-learn/blob/1.6.1/sklearn/ensemble/_voting.py)

**三项验证 · 把同一来源的样本留在一侧。** scikit-learn 的 `GroupKFold` 将同组样本分到同一折，每组恰好留出一次。B 可按整根轴承留出，C 按 `(source_subset, unit)` 留出，并分别汇报各子集误差。A 还需要保持时间方向，应以前期完整来源批次训练、用后续完整批次检验。普通分组折叠本身不保证该顺序。若初始检查点已见过候选留出组，其结果只能用作训练数据诊断。比较训练换序时，固定训练样本、检查点、超参数及评价组，只改变允许变化的到达或遍历次序。推理换序则按样本 ID 对齐逐项比较。两项检验回答不同的问题。[GroupKFold 源码，1.6.1](https://github.com/scikit-learn/scikit-learn/blob/1.6.1/sklearn/model_selection/_split.py)
