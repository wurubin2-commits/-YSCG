## 1. 会议纪要解读 → 对系统的硬约束

| 规则原文要点 | 对现有设计的冲击 | 修正方向 |
|---|---|---|
| 赛题本质是"造工具"不是"刷模型"，交付 Harness/Agent | 我们五步闭环方向正确，但"跑分"不是目标 | 交付物=可自循环的 Harness；模型/策略皆可替换组件 |
| 4 核 8G、**无 GPU**、**断外网**、禁外部 API | 现有 Keras MLP（TF）路线不可行；`requests` 外联需收敛到平台网关 | 主路线 LightGBM/sklearn（CPU）；MLP 降级为可选、默认不装 TF |
| 镜像 **≤2GB**、**严禁打包模型权重**、只给模型 ID+API Key | 我们的"预置训练好模型"设想作废 | 启动时即时训练；LLM 只走平台模型服务 |
| 仅 **千问 3.8-27B / 3.5-4B**；4B 相对 27B **加分** | `OpenAIAdvisor` 模型名需可配为 4B | 默认 4B；策略建议离线固化，评测期不依赖在线 LLM |
| B 包评测流上**系统总能拿到标签**，无需消耗配额 | **现有 `annotation()` 标注预算机制是错的** | 改为"标签总可得"：有标签流直接读 truth；预算改为 CPU 时间/迭代次数 |
| 评分 **35 客观 + 65 主观**；须超官方静态基线；≥3 次迭代 | 现有"增益/成本"指标方向对，但成本口径是伪 GPU | 客观：漂移流平均增益、防过拟合、迭代周期、资源效率（CPU 秒）；主观：受控叙事 |
| 必须 Swan Lab **公开**记录、**人工干预即出局** | 已有 swanlab 接入 | 补"≥3 次迭代"与"零人工"自检清单；每步 log |
| B 包**按批次串行下发**，考泛化与稳定 | 现有单流离线仿真 → 需在线增量、逐批输出、不可回头 | 流式增量 update + 每批产出输出/下线判断 |

**最重要的修正**：把"标注配额"从系统里拿掉——评测流标签总可得，成本只看 **CPU 时间 / 迭代次数 / 镜像体积 / Token**。

## 2. 三个数据集解读 → 任务类型与数据接口

| 数据集 | 任务 | 形状/特征 | 漂移特性 | 适合的指标 |
|---|---|---|---|---|
| **CMAPSS**（NASA 发动机仿真） | **RUL 回归**（剩余寿命） | 21 传感器 + 3 设定，多机组 run-to-failure 时序；FD001–FD004 | 退化累积 + 工况变化 | RMSE / MAE / R² |
| **Gas sensor drift**（UCI 224） | **多分类**（6 类气体） | 16 传感器 × 8 特征 = 128 维；10 批次跨 36 个月 | **典型概念/协变量漂移**（传感器老化） | Accuracy / macro-F1 |
| **XJTU-SY 轴承** | **退化/RUL 回归 + 故障分类** | 水平/垂直振动，25.6kHz，多工况（35Hz-12kN 等） | 磨损退化 + 工况漂移 | RMSE / MAE / F1 |

结论：
- 三者恰好覆盖「**分类漂移**（Gas）+ **回归退化**（CMAPSS/轴承）」，正是官方说的"同时处理三个正交任务以兼顾泛化"。
- 现有系统只有 `accuracy` 一个指标、只支持分类 → **必须补 TaskSpec（分类/回归）+ 指标层 + 时序窗口特征化**。
- 三者都是**时间序列**，不是表格独立同分布样本 → 数据层要加滑窗特征（均值/方差/斜率/频谱）与按时间切分。

## 3. 两篇论文解读 → 理论框架与叙事

### 3.1 论文一《化工科研范式智能化转型的思考与展望》
核心论点：
- 化工研发从"**经验指导实验**"转向"**数据/模型驱动、无人干预的自主实验闭环**"；
- "**机器化学家**"已能完成「文献阅读 → 实验设计 → 自主优化」全流程；
- 提出智能化**成熟度 L0–L4**：L0 传统 → L1 信息化 → L2 数字化 → L3 局部智能化 → L4 全面智能化；
- 智能科研 = 智能计算 + 智能流程 + 智能服务 + 智能外延。

**映射到本赛题**：
- 我们的 Harness 就是"**机器训练师**"——把"机器化学家"从化学实验搬到"模型训练"：
  「监控 → 诊断 → 实验设计(HPO) → 评估 → 上线/回滚」= 论文的「感知 → 假设 → 实验 → 分析 → 沉淀」。
- 用 **L0–L4 成熟度**讲我们的演进路线：当前代码 ≈ L2（数字化闭环）→ 目标 L3（局部智能：规则兜底+LLM 顾问+准入制）→ 展望 L4（全面智能）。
- "**受控的自动化改进**"直接对应我们的**准入制 + 回滚护栏 + 预算硬顶**。

### 3.2 论文二《多能互补新范式下的储能系统多尺度智能设计与调控》
核心论点：
- 储能系统要跨 **材料 → 器件 → 系统 → 电网** 多尺度建模；
- **设计（design）与调控（control）协同**：离线智能设计 + 在线 RL/MPC 调度；
- 用深度强化学习做大规模实时调度；多能互补 → 多目标协同。

**映射到本赛题**：
- 我们的"多尺度自进化"：
  - **模型层**（参数/结构，快尺度）←→ 材料/器件尺度；
  - **策略层**（阈值/预算/触发，慢尺度）←→ 系统/调度尺度；
  - **系统层**（任务选择/评测协议/准入，更慢）←→ 电网/多能互补尺度；
- "设计 + 调控"→ 我们的「实验设计（HPO/搜索空间）+ 策略调控（触发阈值/预算闸门/准入）」；
- 多能互补 → 多任务（Gas/轴承/CMAPSS）协同与资源分配。

## 5. 改进方案（按优先级）

### P0（本轮已开始落地）
1. **数据层**：`TaskSpec`（分类/回归）+ 三数据集适配器 + `LabeledStream`（标签总可得）+ 时序窗口特征。
2. **模型层**：去掉 TF 主依赖；LGBM / sklearn 回归；`predict()` 接口。
3. **指标层**：分类/回归统一"越高越好"的 score；防过拟合用滚动留出验证。

### P1
4. 成本/资源模型：CPU 秒 / 迭代次数 / 镜像体积；每步记 `cost/cpu_seconds`。
5. 千问 4B 顾问 + 评测期离线固化；Token 预算。
6. 多任务串行 + B 包增量更新；每批输出。

### P2
7. 叙事升级（机器训练师 / 多尺度 RSI / L0–L4）+ 答辩材料（对齐 65 主观分）。
8. 准入制与回归任务适配（锚点/记忆在回归下用 MAE 口径）。
